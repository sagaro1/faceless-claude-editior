# Reference videos

Drop reference videos here (any format: .mp4, .mov, .webm, .mkv). Example: Shorts or long videos whose style you want copied.

Optional: add a `.txt` file with the same name as the video to say what to copy from it, for example `anchor_style.txt`:

    copy the caption style and the pacing, ignore the music

Then ask Claude to "analyze the references", and it will look at the frames, pacing, captions, and audio and apply them to the next video.
